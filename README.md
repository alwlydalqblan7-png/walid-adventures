# مغامرات وليد التعليمية

مشروع تطبيق أندرويد للصف الخامس السوري، مبني ليعمل دون إنترنت على جوال الطفل ويزامن التقدم مع جوال ولي الأمر عند توفر الاتصال.

## المسار التعليمي

كل مادة مستقلة، وداخلها: الوحدة ثم الدرس، عرض مبسط للدرس، مغامرة تدريبية، اختبار إتقان، مكافأة، ثم مراجعة ذكية خلال 48 ساعة.

## حالة النسخة

- النموذج التفاعلي لدرس «السمكة الذهبية» موجود في `www/index.html`.
- شخصيتا وليد الحقيقي والكرتوني مدمجتان في النموذج.
- شخصيتا الأب الجادة والمشجعة جاهزتان للتنبيهات.
- فهرسة الكتب وتحويل الدروس إلى محتوى تفاعلي قيد التنفيذ.
- المزامنة بين الجهازين ستُضاف بعد تثبيت نموذج المحتوى المحلي.

## البناء لأندرويد

يتطلب Node.js وJava 17 وAndroid SDK. بعد تثبيت الحزم: `npm install` ثم `npm run android:add` ثم `npm run android:sync`.
